# CurtainLights guides

Static mirror of the CurtainLights buying guides about LED curtain lights: types, sizes, power, weather ratings, smart and animated curtains, and ideas for windows, bedrooms and Halloween.

The main site is **https://curtainlights.pages.dev**. Pages here point to it as the canonical version.

Some guides mention a product from Lumalyn, with which CurtainLights is affiliated; those links are marked as partner links.
